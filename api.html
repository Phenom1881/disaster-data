The DisasterData API

Federal disaster declarations by state, county and declaration number, and each state's own weather emergency declarations matched to federal declarations and NOAA storm reports. Free, read-only JSON. No key, no sign-up.

Quick start

One request, one answer.

Everything is a GET request that returns JSON. Declarations naming Roanoke County, Virginia, since 2020:

// JavaScript
const r = await fetch('https://disasterdata-api.disasterdata.workers.dev/v1/counties/51161?type=EM&since=2020-01-01');
const { name, count, declarations } = await r.json();

# curl
curl 'https://disasterdata-api.disasterdata.workers.dev/v1/states/VA/crosswalk'

# Python
import requests
data = requests.get('https://disasterdata-api.disasterdata.workers.dev/v1/states/FL/actions').json()

The root address lists every endpoint. The API reads the same files this site publishes, so an answer from it always matches what the site shows, and it updates on the same weekly schedule.

Endpoints

What you can ask.

Replace {ST} with a postal code such as VA. Federal data covers the states, the District of Columbia and the territories. State weather declarations cover the 50 states.

GET/v1/states

Every state and territory with its count of federal declarations, its number of localities, and, for the 50 states, its count of state weather declarations.

Try it: /v1/states

{
  "api_version": "v1",
  "data_date": "2026-10-08",
  "count": 56,
  "states": [
    { "state": "AK", "name": "Alaska", "federal_declarations": 95,
      "jurisdictions": 32, "state_declarations": 23, "href": "/v1/states/AK" }
  ],
  "sources": ["https://disasterdata.io/data/decl-index/manifest.json"],
  "attribution": "..."
}
GET/v1/states/{ST}

One state in a single answer: federal declaration totals by type, its most recent federal declaration, and how many state weather declarations it has, with the coverage note that goes with them. Includes links to the other endpoints for that state.

ParameterMeaning
{ST}Two letter postal code, for example VA.

Try it: /v1/states/VA

GET/v1/states/{ST}/declarations

A state's federal declarations, newest first. Each lists every county or equivalent it names, by FIPS code, and whether FEMA designated the whole state.

ParameterMeaning
{ST}Two letter postal code, for example VA.
typeDR, EM or FM: major disaster, emergency, or fire management assistance.
sinceOnly declarations on or after this date, written YYYY-MM-DD.
untilOnly declarations on or before this date, written YYYY-MM-DD.

Try it: /v1/states/VA/declarations?type=EM&since=2020-01-01

{
  "state": "VA",
  "count": 12,
  "filters": { "type": "EM", "since": "2020-01-01" },
  "declarations": [
    { "fema_id": "DR-4863-VA", "id": "DR-4863", "type": "DR",
      "title": "SEVERE WINTER STORMS AND FLOODING",
      "incidentType": "Severe Storm",
      "date": "2025-04-04", "begin": "2025-02-10", "end": "2025-02-18",
      "statewide": false, "programs": ["PA"],
      "fips": ["51007", "51011", "..."] }
  ]
}

date is the declaration date. begin and end are the incident period.

GET/v1/declarations/{id}

One federal declaration, written the way FEMA writes it: type, number, then state. Returns its dates, incident period, programs, and the named areas with their FIPS codes and names.

ParameterMeaning
{id}For example DR-4898-TN or EM-3592-FL: type, number, two letter state.

Try it: /v1/declarations/DR-4863-VA

GET/v1/counties/{FIPS}

Every federal declaration that names one county, including statewide declarations, which name every county in the state. Each is marked county or statewide.

ParameterMeaning
{FIPS}Five digit county FIPS code. 51161 is Roanoke County, Virginia.
typeDR, EM or FM: major disaster, emergency, or fire management assistance.
sinceOnly declarations on or after this date, written YYYY-MM-DD.
untilOnly declarations on or before this date, written YYYY-MM-DD.

Try it: /v1/counties/51161?type=EM&since=2020-01-01

GET/v1/states/{ST}/actions

The state's own weather emergency declarations: the governor, the signing date, the order number and a link to the source record. The response also carries the coverage note, which says how far back that state's archive goes and what is missing.

ParameterMeaning
{ST}Two letter postal code of one of the 50 states.

Try it: /v1/states/FL/actions

{
  "state": "FL",
  "name": "Florida",
  "generated_on": "2026-10-08",
  "coverage": "2020-present structured Governor archive; ...",
  "count": 26,
  "actions": [
    { "declaration_id": "FL-EO-2026-202",
      "governor": "Ron DeSantis",
      "action_number": "2026-202",
      "date_signed": "2026-10-06",
      "title": "#2026-202 re: Emergency Management: Tropical Depression Nine",
      "source_url": "https://www.flgov.com/eog/news/executive-orders" }
  ]
}

Only original weather declarations are listed. Extensions, amendments, administrative orders and records reviewed as not a weather event are left out.

GET/v1/states/{ST}/crosswalk

Each state declaration beside its closest federal declaration and the NOAA Storm Events zones and counties matched to it. This is the join behind the Plus pages.

ParameterMeaning
{ST}Two letter postal code of one of the 50 states.

Try it: /v1/states/FL/crosswalk

{
  "declaration_id": "FL-EO-2026-33",
  "date_signed": "2026-02-09",
  "federal_status": "no_federal_declaration_found",
  "federal_declaration": null,
  "noaa_status": "matched",
  "noaa_match_count": 128,
  "noaa_areas": ["BAKER", "COASTAL BAY", "..."]
}

federal_declaration is an automated candidate: the closest federal declaration whose incident period falls within 21 days of the state signing date. It is not a confirmed legal link. A federal_status of no_federal_declaration_found is a result, not missing data. A declaration signed after the NOAA data ends shows no storm match yet.

GET/v1/health

A service check. Not rate limited.

Try it: /v1/health

{ "api_version": "v1", "status": "ok" }
Reference

Every response has the same frame.

api_version is v1. data_date or generated_on says when the underlying file was built. sources lists the published files the answer came from. attribution carries the credit line, which you should keep with the data if you republish it.

Errors are JSON with an error message and the status:

400
A parameter is malformed: a date not written YYYY-MM-DD, a type other than DR, EM or FM, a declaration id not written like DR-4898-TN, or a county that is not five digits.
404
Nothing there: an unknown state, a county no declaration names, or a declaration that is not in the published data.
429
Rate limit reached. Wait a minute. The Retry-After header says how long.
502 and 503
The data file could not be read, or a state's declaration data is not published yet. Try again shortly.
Using it

Limits and good manners.

Rate limit. 60 requests a minute per IP address, which covers pulling every state. Past that the API answers 429.

Caching. Data changes once a week. Responses can be cached for an hour, and you are welcome to cache longer.

Browsers. Cross-origin requests are allowed, so you can call the API from a web page. GET only.

Stability. Fields may be added inside /v1. Nothing will be renamed or removed without a new version path.

Need more? If you need more than the public limit, or a feed built for your system, get in touch.

About the data

Read this before you build on it.

Federal declarations come from OpenFEMA's Disaster Declarations Summaries, with the counties each declaration names.

State declarations are collected from each state's own records. Coverage varies by state, and a missing declaration is not evidence that none was signed. Each state's response carries a coverage note that says how far back its archive goes and what is not covered. The Plus pages show the same notes.

Storm matches use NOAA's Storm Events database, which runs about two months behind. A recent declaration shows no storm match until the data catches up.

Candidate matches are not legal links. The federal match for a state declaration is an automated candidate based on dates.

DisasterData.IO uses OpenFEMA and NOAA data and is not endorsed by or affiliated with FEMA or NOAA. If something looks wrong, report a data issue.
